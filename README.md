# НейроКвест 🐾 — приключение с кошечкой Луней

Готовый мини-сайт для GitHub Pages на **HTML / CSS / JavaScript**. Для 1–4 классов: шесть миссий, финальное испытание, анимированная кошечка с подсказками, звёзды, прогресс и диплом для печати.

## Установка на GitHub Pages

1. Создайте публичный репозиторий в GitHub, например `neuroquest`.
2. Загрузите **все файлы и папку `assets`** в корень репозитория. Удобнее всего распаковать архив и загрузить содержимое папки `neuroquest`, а не саму папку.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку **main** и папку **/(root)**, сохраните.
5. После публикации откройте ссылку вида `https://ВАШ-ЛОГИН.github.io/neuroquest/`.

Можно также открыть `index.html` двойным щелчком в браузере — для игры сервер не обязателен.

## Настройка для вашей школы

Отредактируйте **`config.js`**:
- `schoolName` — название школы;
- `courseName` — название курса;
- `courseDescription` — описание;
- `courseUrl` — **полная https-ссылка на запись**;
- `contactText` — текст, если ссылки пока нет.

Без заполнения `courseUrl` кнопка ведёт на информацию для родителей, а не на выдуманную страницу.

## Педагогические примечания

- **Никакой сторонней большой нейросети** сайт не вызывает. Конструктор промптов собирает текст и показывает игровой символический предварительный просмотр — не генерирует картинку в реальном времени. Это прямо подписано в интерфейсе.
- «Обучи робота» использует простую модель **ближайшего обучающего примера** в JavaScript, чтобы наглядно показать зависимость результата от разметки обучающих данных. Это учебная модель, не полноценная нейросеть.
- Для игры «Фото или ИИ» предоставлены локальные иллюстрации, созданные ИИ, и локальные фотографии. Чтобы усложнить уровень, при необходимости замените изображения на картинки, права на публикацию которых у вас есть, сохраняя имена файлов.
- Дизайн светлый, адаптирован для телефонов, планшетов и компьютеров. Работает без загрузки шрифтов и скриптов из интернета.
- Состояние прогресса сохраняется **только в `localStorage` браузера** ребёнка. Имя на дипломе не хранится, не пересылается и исчезает после обновления вкладки.
- Внешнего сбора персональных данных, аналитики и рекламных трекеров нет.

## Изменение игровых заданий

Тексты, правильные ответы и содержимое уровней задаются в массивах в `script.js`: `photos`, `abilities`, `promptQuizzes`, `animalTrain`, `animalTest`, `mistakes`, `safety` и `boss`.

## Как сохранить диплом

После завершения игры впишите имя по желанию и нажмите «Сохранить диплом в PDF». В системном диалоге печати выберите **«Сохранить как PDF»**.
